# Rule: plan files are living documents

- Plan files are named `{goal}_{YYYY-MM-DD}.md` and live in `plans/`.
- A plan is a **living document**: append results and decisions as you go —
  do **not** overwrite or delete earlier sections. The history is the value.
- When a phase completes, append what actually happened (numbers, file paths,
  surprises) beneath that phase — not just "done".
- If the plan and the code diverge, reconcile deliberately: fix one, note why.
